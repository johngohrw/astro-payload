### #2 — Deduplicate payloadQuery factories into createPayloadQuery
**Problem:** All three astro packages contained nearly identical `payloadQuery.ts` files (~12 lines each), violating DRY.
**Files:**
- `sites/default/astro/src/utils/createPayloadQuery.ts` (new)
- `sites/default/astro/src/utils/payloadQuery.ts` (refactored)
- `sites/teleplex/astro/src/utils/payloadQuery.ts` (refactored)

**Tests:** `astro-default` build ✅ (5 pages), `astro-teleplex` build ✅ (7 pages).
**Commit:** `b0a0c3a`

### #3 — Align Teleplex frontend types with its own backend
**Problem:** `astro-teleplex` depended on `payload-default` for types, but `payload-teleplex` is the actual backend. Types could diverge silently.
**Files:** `sites/teleplex/astro/package.json`, `sites/teleplex/astro/src/utils/payloadQuery.ts`
**Change:** Swapped `payload-default: workspace:*` → `payload-teleplex: workspace:*` and updated `Config` import.
**Tests:** `astro-teleplex` build ✅.
**Commit:** `2671763`

### #4 — Restrict Teleplex Media to images only

**Files:** `sites/teleplex/payload/src/collections/Media.ts`
**Change:** Removed `video/*` from `mimeTypes`. Restored consistency with `payload-default` and `payload-quine`.
**Tests:** `generate:types` ✅ in teleplex payload.
**Commit:** `e7731ea`

### #5 — Re-export Quine Media from payload-default

**Change:** Added `export { Media }` to `payload-default`'s `index.ts`, then replaced quine's duplication with `export { Media } from "payload-default"`.
**Tests:** `generate:types` ✅ in quine payload, `astro-quine` build ✅.
**Commit:** `98597cf`
