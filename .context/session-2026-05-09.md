## Decisions & Rationale
- **Global pnpm over corepack:** Corepack's cache lives in `/root/.cache/` which is inaccessible to non-root users. Global npm install works for any UID.
- **su-exec over `USER` directive:** Setting `USER node` in Dockerfile breaks because the image is built as root and pnpm needs to be available to the runtime user. Using `su-exec` in the entrypoint allows runtime privilege dropping based on env vars.
- **Fat-stack image remains:** Standalone output was previously abandoned due to pnpm workspace symlink issues. No attempt to revisit.
- **GHCR over Docker Hub:** Repo is already on GitHub; GHCR is free for public repos and uses the same auth as GitHub.
